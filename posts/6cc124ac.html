一、什么是 Tampermonkey（篡改猴）？

Tampermonkey 是一款免费的浏览器用户脚本管理器，俗称“篡改猴”或“油猴”。
它就像浏览器的“外挂平台”，允许你安装各种由 JavaScript 编写的小脚本，用来修改网页的行为、外观或功能。

能做什么？

  • 屏蔽广告、解除复制限制、自动翻页
  • 下载网页视频、网盘直链提取、搜索引擎去重
  • 增强网页功能（如知乎免登录看全文、百度网盘简易下载）
  • 只要你能想到的网页修改，基本都能通过脚本实现

二、安装 Tampermonkey 扩展

1. 选择你的浏览器

Tampermonkey 支持 Chrome、Edge、Firefox、Safari、Opera 等主流浏览器。下面以 Chrome 为例，其他浏览器步骤几乎一样。

2. 进入扩展商店

  • Chrome 浏览器

    访问 Chrome 网上应用店，搜索 Tampermonkey

  • Edge 浏览器

    直接访问扩展页面 ”edge://extensions/ “ 或从设置中进去如下图

搜索篡改猴点击获取

安装成功后固定在工具栏

  • 无法访问扩展商店

可以访问篡改猴官方网站直接下载 .crx 文件，然后开启浏览器开发者模式，拖入安装。

三、启用“允许用户脚本”扩展设置

以Edge 浏览器为例，勾选允许用户脚本：

四、如何安装 JS 脚本？

方法一：从脚本网站一键安装

最知名的用户脚本分享站是 Greasy Fork：https://greasyfork.org/zh-CN
里面所有脚本都适用于 Tampermonkey。

步骤：

  1. 打开 Greasy Fork，搜索你需要的功能，比如“百度网盘”、“知乎免登录”。
  2. 进入脚本详情页，点击绿色的 “安装此脚本” 按钮。
  3. 油猴会自动弹出安装界面，显示脚本名称、版本、包含的网址等信息。
  4. 点击 “安装” 按钮，脚本即添加完成。
  5. 去对应的网页刷新，脚本就会自动运行。

方法二：手动添加脚本

如果别人直接给了你一段 .user.js 代码，或者你想自己写一个小脚本，可以手动添加。

步骤：

  1. 单击油猴图标 → “管理面板”（或右键图标 → 选项，再进入“已安装脚本”）。
  2. 把脚本拖入安装。
